# Proposal: Add Privacy Policy Page

## Why
To enhance user trust and compliance, users need to be able to view the privacy policy details.

## What
Add a new "Privacy Policy" page accessible from the "My" (Profile) tab.
- The page will display the privacy policy text (using mock/static data).

## Impact
- **New Page:** `PrivacyPolicyPage`
- **Navigation:** Update `MyPage` to include a link to `PrivacyPolicyPage`.
- **Data:** Display static privacy policy text.
