# 重构提油订单列表项操作方式

## Why（为什么需要这个改变）

当前提油订单列表项的交互设计存在以下问题：

1. **操作不够明确**：用户需要点击整个卡片才能进入详情，但卡片上没有明确的"查看详情"按钮，对于新用户不够友好
2. **取消操作位置不当**：取消按钮独立放置在卡片底部，与其他信息分离，不符合常见的操作按钮组布局
3. **缺少操作区分**：待提油和已完成订单的操作应该有明显区分，当前设计没有体现这一点
4. **箭头图标冗余**：右侧箭头图标暗示可点击，但实际上整个卡片都可点击，造成视觉混乱

## What（要做什么改变）

### UI 改变
1. **移除右侧箭头图标**：从卡片主体部分移除 `Icons.chevron_right` 图标
2. **新增操作按钮区域**：在底部添加操作按钮组
   - **取消订单**按钮（仅待提油状态显示）：灰色边框 + 灰色文字，完全圆角
   - **查看详情**按钮（所有状态都显示）：紫色边框 + 紫色文字，完全圆角

### 交互改变
1. **移除卡片点击事件**：去掉 `GestureDetector` 的 `onTapUp` 跳转逻辑
2. **按钮化操作**：
   - 点击"查看详情"按钮 → 跳转到订单详情页
   - 点击"取消订单"按钮 → 弹出确认对话框

### 布局改变

│ ─────────────────────────────── │

## Impact（影响范围）

### 文件影响
- **修改**：`lib/pages/pickup_order_list/widgets/pickup_order_list_item.dart`
  - 移除 `GestureDetector` 的点击跳转逻辑
  - 移除箭头图标
  - 重构 `_buildCardFooter` 方法，添加按钮组
  - 移除 `_buildCancelButton` 方法（集成到 footer）
  - 添加 `_buildActionButtons` 方法

### 用户体验影响
- ✅ **提升**：操作更加明确，用户知道点击哪里进行什么操作
- ✅ **提升**：符合移动端常见的操作模式（底部操作按钮）
- ✅ **提升**：视觉更加清晰，减少冗余元素

### 兼容性影响
- ⚠️ **无破坏性改变**：仅改变 UI 交互方式，不影响数据结构和 API

### 性能影响
- ✅ **无影响**：仅 UI 调整，无性能开销变化
