# 提油订单列表项 UI/UX 规范

## MODIFIED Requirements

### 列表项交互规范

**原有规范**：
- 用户可以点击整个卡片跳转到订单详情页
- 卡片右侧显示箭头图标表示可点击
- 取消订单按钮单独显示在卡片底部

**新规范**：
- 用户**不能**点击整个卡片跳转
- 卡片**不显示**右侧箭头图标
- 操作按钮**必须**集中在卡片底部的操作区域
- 操作按钮**必须**包括：
  - **查看详情**按钮（所有状态）
  - **取消订单**按钮（仅待提油状态）

### 操作按钮样式规范

**取消订单按钮**（次要操作）：
- 边框：灰色 `#D1D5DB`，宽度 `1px`
- 背景：白色
- 文字：灰色 `#6B7280`，字重 `w500`，字号 `13px`
- 圆角：`20px`（完全圆角）
- 内边距：垂直 `10px`，水平 `16px`

**查看详情按钮**（主操作）：
- 边框：紫色 `#7165E3`，宽度 `1px`
- 背景：白色
- 文字：紫色 `#7165E3`，字重 `w500`，字号 `13px`
- 圆角：`20px`（完全圆角）
- 内边距：垂直 `10px`，水平 `16px`

**已完成状态**：


### 交互行为规范

1. **查看详情按钮**：
   - 点击后跳转到 `AppPage.pickupOrderDetailPage`
   - 传递当前订单对象

2. **取消订单按钮**：
   - 点击后显示确认对话框
   - 对话框标题：`取消订单`
   - 对话框内容：`确定要取消该提油订单吗？取消后无法恢复。`
   - 确认后调用 `PickupOrderListCtrl.cancelOrder()`

3. **卡片点击**：
   - **不再**响应点击事件跳转
   - 保留视觉反馈效果（按下缩放动画）
