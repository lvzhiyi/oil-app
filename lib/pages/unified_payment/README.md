# 统一支付页面

## 概述

统一支付页面合并了原有的"余额充值"和"购买彩票套餐"功能，提供一站式的支付体验。

## 主要功能

### 1. 支付类型切换
- **余额充值**: 用于为动态二维码生成充值余额
- **套餐购买**: 用于购买彩票套餐，直接走支付流程

### 2. 余额充值功能
- 自定义充值金额输入
- 快捷金额选择（100、200、500、1000、2000、5000元）
- 最低充值金额限制（100元）
- 实时金额验证

### 3. 套餐购买功能
- 多种套餐选择（100张、500张、1000张）
- 套餐详情展示（张数、单价、总价、描述）
- 热门套餐标识
- 直接支付套餐完整金额（不支持余额扣减）

### 4. 支付方式说明
- **余额充值**: 充值的金额用于生成动态二维码
- **套餐购买**: 直接支付套餐完整金额，不使用账户余额扣减

### 5. 统一支付流程
- 支持第三方在线支付
- WebView支付页面集成
- 支付结果处理（成功/失败/取消）
- 订单状态管理

## 技术特点

### 1. 现代化UI设计
- 卡片式布局
- 渐变色彩搭配
- 圆角设计元素
- 阴影效果

### 2. 状态管理
- 使用BLoC模式进行状态管理
- 响应式UI更新
- 错误状态处理

### 3. 用户体验优化
- 加载状态显示
- 表单验证反馈
- 智能默认值设置
- 便捷操作流程

## 页面结构

```
UnifiedPaymentPage
├── UnifiedPaymentView (主视图)
├── UnifiedPaymentCtrl (控制器)
├── UnifiedPaymentState (状态管理)
├── UnifiedPaymentType (数据模型)
└── PackageSelector (套餐选择器组件)
```

## 导航入口

- **仪表盘页面**: 支付中心按钮
- **仪表盘页面**: 购买彩票按钮
- **路由路径**: `/unifiedPayment`

## 数据流

1. 用户选择支付类型（充值/购买）
2. 根据类型显示对应的输入界面
3. 用户输入金额或选择套餐
4. 系统验证输入有效性
5. 发起支付请求
6. 打开WebView支付页面
7. 处理支付结果并更新状态
