## AppSize.boxShadow 构成解析

`AppSize.boxShadow` 是项目中定义的标准阴影样式，用于确保 UI 组件在视觉上的一致性。该阴影配置位于 `lib/resources/size.dart` 文件中，具体构成如下：

- **颜色（Color）**: `#e6e6e6`（100% 不透明度）
- **偏移（Offset）**: `(0, 4)`
- **模糊半径（Blur Radius）**: `pt(8)`（通过 `pt` 工具函数进行响应式转换）
- **扩散半径（Spread Radius）**: `0`

此阴影设计旨在提供一种轻柔、现代的视觉提升效果，适用于卡片、容器等需要轻微立体感的 UI 元素。

## 组件中的阴影应用

### 卡片组件
在 `SectionCard` 等卡片式容器组件中，`AppSize.boxShadow` 被广泛使用以创建清晰的视觉层次。卡片通过阴影与背景分离，突出其作为信息区块的独立性，同时保持整体界面的简洁。

### 按钮组件
虽然主要按钮（Primary Button）使用了品牌紫色的专用阴影，但部分次要或自定义按钮组件在需要时会采用 `AppSize.boxShadow` 以保持与整体设计语言的一致性。标准按钮的阴影通常更强调垂直偏移和模糊，以增强可点击性。

### 顶部导航栏（TopBar）
TopBar 组件使用了与 `AppSize.boxShadow` 类似但更微妙的阴影，其偏移为 `(0, 4)`，模糊半径为 `3`，颜色为黑色 1% 透明度。这与 `AppSize.boxShadow` 的 `(0, 4)` 偏移一致，但整体更轻，以避免在页面顶部造成过重的视觉负担。

## 不同组件的阴影差异对比

| 组件 | 颜色 | 偏移 (x, y) | 模糊半径 | 扩散半径 | 来源 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **AppSize.boxShadow (标准)** | `#e6e6e6` | `(0, 4)` | `8` | `0` | `size.dart` |
| **按钮 (Primary Button)** | `#7165E3` (40% 透明) | `(0, 2)` | `4` | `1` | `project.md`, `UI_SPECIFICATION.md` |
| **TopBar** | 黑色 (1% 透明) | `(0, 4)` | `3` | `2` | `topbar.dart`, `UI_SPECIFICATION.md` |
| **库存列表项** | 黑色 (2% 透明) | `(0, 2)` | `8` | - | `spec.md` |

**分析说明**:
- **偏移差异**: 按钮的偏移 `(0, 2)` 比标准的 `(0, 4)` 更小，使其看起来更“贴地”，强调其可交互性。而 TopBar 和标准阴影使用 `(0, 4)` 的偏移，以创建更强的分层效果。
- **模糊与扩散**: 按钮阴影扩散半径为 `1`，使其轮廓更清晰；TopBar 阴影扩散半径为 `2`，模糊为 `3`，形成更柔和的渐变；标准阴影则无扩散，模糊为 `8`，提供更明显的深度感。
- **颜色**: 不同组件根据其功能和品牌要求使用不同的阴影颜色，从品牌色到中性黑/灰。

## 阴影使用规范与约束

为确保 UI 的一致性与可维护性，项目制定了严格的阴影使用规范：

1.  **必须使用常量**: 所有阴影效果必须使用预定义的常量，如 `AppSize.boxShadow` 或设计规范中明确定义的常量。禁止在代码中直接硬编码 `BoxShadow` 参数。
2.  **禁止硬编码**: 直接在组件中创建 `BoxShadow` 实例（如 `BoxShadow(color: Colors.grey, offset: Offset(0, 2))`）是严格禁止的，这会导致样式分散和难以维护。
3.  **遵循设计规范**: 开发人员应参考 `UI_SPECIFICATION.md` 和 `openspec` 目录下的设计文档，了解不同组件应使用的具体阴影样式。
4.  **主题适配**: 阴影颜色应考虑主题切换，但 `AppSize.boxShadow` 使用的 `#e6e6e6` 是一个中性色，在浅色和深色主题下均能保持良好的视觉效果。
