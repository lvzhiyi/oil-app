## 引言
本文档详细说明油品业务应用中的水平与垂直间距标准，旨在统一UI设计与开发实现的一致性。通过定义标准化的间距常量和响应式适配方法，确保在不同设备和屏幕尺寸下均能保持良好的视觉体验和布局一致性。所有间距均通过 `AppSize` 常量或 `pt()` 方法实现，禁止硬编码像素值。

## AppSize.pagePadding 定义与应用

`AppSize.pagePadding` 是应用中页面内容区域的标准内边距，定义如下：

```dart
static final EdgeInsets pagePadding = 
    EdgeInsets.symmetric(vertical: 0, horizontal: pt(12));
```

该定义表示：
- **水平方向**：左右内边距为 `pt(12)`，即12pt的响应式间距
- **垂直方向**：上下内边距为0pt

此配置适用于大多数页面布局场景，确保内容不会紧贴屏幕边缘，同时保持顶部和底部的紧凑布局。`pagePadding` 被广泛应用于各类页面容器中，作为基础布局的内边距标准。

## 响应式适配机制

应用通过 `pt()` 方法实现响应式间距适配，其核心逻辑位于 `lib/utils/pt.dart` 文件中：

```dart
pt(double size, {double padScale = 0.625, double landscapeScale = 0.432, bool isPad = false}) {
  double _size = screen.getWidth(size, padScale: padScale, landscapeScale: landscapeScale, isPad: isPad);
  return _size;
}
```

`pt()` 方法根据设备类型和屏幕方向动态调整尺寸：
- **默认设备**：直接使用传入的尺寸值
- **平板设备**：应用 `0.625` 的缩放比例，使间距更宽松
- **横屏模式**：应用 `0.432` 的缩放比例，优化宽屏布局

这种机制确保了在不同设备上都能获得合适的视觉间距，避免在大屏设备上间距过大或在小屏设备上拥挤的问题。

## 水平间距规范

水平间距用于控制元素间的左右间隔，具体规范如下：

| 间距值 | 使用场景 |
|-------|---------|
| 8 | 最小间距 |
| 10 | 小间距 |
| 12 | 图标间距 |
| 15 | 标准间距 |
| 18-20 | 页面左右边距 |
| 22 | 大间距 |
| 24 | 块间距 |

**典型应用场景**：
- **图标间距**：使用 `pt(12)` 作为图标与文本或其他图标的间隔
- **页面边距**：页面内容与屏幕边缘的距离采用 `18-20pt`，通过 `pt(18)` 或 `pt(20)` 实现
- **按钮内间距**：按钮内部元素（如图标与文字）使用 `pt(12)` 间距

这些间距值均通过 `pt()` 方法调用，确保响应式适配。

## 垂直间距规范

垂直间距用于控制元素间的上下间隔，具体规范如下：

| 间距值 | 使用场景 |
|-------|---------|
| 5 | 最小间距 |
| 10 | 小间距 |
| 12 | 标签与内容间距 |
| 15 | 标准间距 |
| 16 | 表单元素间距 |
| 20 | 大间距、组块间距 |
| 25 | 提示文本上方间距 |
| 32 | 表单与输入框顶部间距 |
| 58 | 页面顶部间距 |
| 61 | 对话框内容间距 |
| 88 | 大块间距 |

**典型应用场景**：
- **标签与内容**：使用 `pt(12)` 作为标签与其对应内容之间的垂直间隔
- **表单元素**：表单中各输入项之间使用 `pt(16)` 的垂直间距
- **表单顶部**：整个表单区域与上方内容之间使用 `pt(32)` 的较大间距，增强视觉分隔

这些规范确保了表单、列表等垂直排列内容的可读性和层次感。

## 间距使用原则

为确保代码一致性和可维护性，必须遵循以下间距使用原则：

1. **统一使用常量或方法**：所有间距必须通过 `AppSize` 常量或 `pt()` 方法设置，禁止直接硬编码像素值。
2. **响应式优先**：在涉及不同设备适配的场景中，优先使用 `pt()` 方法而非固定数值。
3. **语义化命名**：对于重复使用的间距，建议在 `AppSize` 类中定义语义化常量，如 `formVerticalSpacing`。
4. **避免魔法数字**：任何涉及尺寸的代码都应通过方法或常量引用，提高代码可读性。

示例：
```dart
// ✅ 正确做法
padding: EdgeInsets.symmetric(horizontal: pt(12))

// ❌ 错误做法
padding: EdgeInsets.symmetric(horizontal: 12)
```

通过严格执行这些原则，可确保应用在各种设备上保持一致的视觉体验和高质量的UI实现。
