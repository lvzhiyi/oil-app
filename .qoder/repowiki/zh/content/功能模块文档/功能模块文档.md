## 用户认证模块

本模块实现了完整的用户认证流程，包括登录、注册、忘记密码和OTP验证功能。系统采用BLoC架构模式，将页面、控制器、状态和视图分离，确保代码的可维护性和可测试性。

### 登录流程

登录功能通过`LoginPage`实现，采用统一登录界面支持密码登录和验证码登录两种方式。页面结构遵循标准的BLoC模式：

- **Page**: `login/page.dart` - 页面入口和路由配置
- **Controller**: `login/controller.dart` - 业务逻辑处理
- **State**: `login/state.dart` - 状态管理
- **View**: `login/view.dart` - UI渲染

登录流程如下：
1. 用户输入手机号
2. 选择密码登录或验证码登录模式
3. 验证表单数据有效性
4. 调用AuthService进行身份验证
5. 处理登录结果并跳转到主页面

```mermaid
sequenceDiagram
participant 用户 as 用户
participant 页面 as LoginPage
participant 控制器 as LoginCtrl
participant 服务 as AuthService
participant API as 后端API
用户->>页面 : 输入手机号和密码/验证码
页面->>控制器 : 提交登录表单
控制器->>控制器 : 验证输入有效性
控制器->>服务 : 调用login()方法
服务->>API : POST /auth/login
API-->>服务 : 返回认证结果
服务-->>控制器 : 返回AuthResponse
控制器->>控制器 : 处理登录成功逻辑
控制器->>页面 : 更新状态(loginSuccess : true)
页面->>主页面 : 导航到首页('/')
```

**表单验证逻辑**：
- 手机号格式验证：使用phone_validator进行格式校验
- 密码强度验证：要求至少6位字符
- 协议勾选验证：必须同意用户协议才能提交
- 错误处理：显示友好的错误消息，如"手机号或密码错误"、"验证码错误或已过期"

**与AuthService的API交互**：
- `authService.login()`：处理用户登录请求
- `authService.sendCode()`：发送验证码
- 使用LoginRequest数据模型封装请求参数

### 注册流程

注册功能通过`RegisterPage`实现，流程包括：
1. 用户填写注册信息（手机号、密码等）
2. 发送验证码进行手机验证
3. 提交注册表单
4. 调用AuthService注册接口
5. 注册成功后跳转到账户创建完成页面

注册页面同样采用BLoC架构，与登录页面共享部分验证逻辑和组件。

### 忘记密码流程

忘记密码功能通过`ForgotPasswordPage`实现，采用三步流程：
1. 输入注册手机号
2. 获取验证码（调用`authService.sendCode()`）
3. 设置新密码

该流程确保了账户安全，防止未经授权的密码修改。


### OTP验证流程

OTP（一次性密码）验证通过`OtpPage`实现，主要用于敏感操作的身份验证：
1. 系统自动发送OTP到用户手机
2. 用户输入收到的验证码
3. 验证OTP有效性
4. 验证通过后执行相应操作

OTP页面设计为可复用组件，可通过extra参数传递上下文信息。

```mermaid
flowchart TD
Start([开始OTP验证]) --> SendOTP["发送OTP到手机"]
SendOTP --> WaitInput["等待用户输入"]
WaitInput --> Validate["验证OTP"]
Validate --> Valid{"OTP有效?"}
Valid --> |是| Success["验证成功<br>执行后续操作"]
Valid --> |否| ShowError["显示错误信息"]
ShowError --> Retry["允许重试"]
Retry --> WaitInput
Success --> End([结束])
```

## 油品业务模块

### 油品采购流程

油品采购功能通过`MainOilPayPage`实现，主要流程如下：

1. 用户进入油品采购页面
2. 选择油库和油品类型
3. 输入采购数量
4. 创建采购订单
5. 跳转到支付流程

```dart

class Depot {
  final int? depotId;
  final String? depotName;
  final String? provinceName;
  final String? cityName;
  final String? areaName;
```

## 加油站管理模块

加油站管理模块提供加油站的列表展示、编辑和绑定功能。

### 加油站列表

`StationListPage`实现了加油站列表功能，支持分页加载：

- 每页显示固定数量的加油站
- 支持下拉刷新
- 支持上拉加载更多

**分页实现**：
通过`station_service.dart`的`getStationStatus()`方法实现分页：

```dart
Future<GetStationResponse> getStationStatus(
  @Query('page') int page,
  @Query('pageSize') int pageSize,
  @Query('statuses') List<String> statuses,
);
```

### 加油站编辑和绑定

加油站编辑和绑定功能通过`StationEditPage`实现：

- **编辑功能**：修改加油站基本信息
- **绑定功能**：将加油站与用户账户关联

**选择UI**：
使用自定义的选择组件，提供良好的用户体验。

**服务调用**：
`station_service.dart`提供了相关API：

- `getStationDetail()`：获取加油站详情
- `bindStation()`：新增加油站
- `updateStation()`：编辑加油站
